# JavaScript Piscine - Advanced Problem Solving

This repository contains my solutions for an intensive JavaScript bootcamp (Piscine). The project consists of over 80 individual exercises designed to master Vanilla JavaScript, from basic language primitives to advanced functional programming, asynchronous operations, and DOM manipulation.

## 🧠 Key Areas Covered

### 🛠️ Functional Programming & Closures
- **Higher-Order Functions:** `mapper.js`, `filter.js`, `reduce.js`
- **Closures & Optimization:** `debounce.js`, `throttle.js`
- **Currying:** `currify.js`, `sweet-curry.js`, `curry-entries.js`

### 🔄 Asynchronous JavaScript
- **Promises & Fetch:** `get-json.js`, `keep-trying-or-giveup.js`
- **Control Flow:** `series.js`, `flow.js`

### 🌐 DOM Manipulation & Events
- **Dynamic Elements:** `build-brick-and-break.js`, `harder-bigger-bolder-stronger.js`
- **Event Listeners:** `mouse-trap.js`, `pick-and-click.js`, `keycodes-symphony.js`

### 📦 Data Structures & Algorithms
- **Object Manipulation:** `deep-copy.js`, `manipulate-values.js`, `manipulate-keys.js`
- **String & Regex:** `ion-out.js`, `vowel-dots.js`, `greedy-url.js`
- **Math & Logic:** `pyramid.js`, `count-leap-years.js`, `triangle.js`

### 🚀 Node.js & Modules (ESM)
- **File System & Modules:** `tell-me-vip.mjs`, `verydisco.mjs`, `friend-support.mjs`

All exercises were implemented from scratch without the use of external libraries, ensuring a deep understanding of JavaScript's core mechanics.
